# Reporting a security concern

Please keep security details private. Do not put credentials, personal information, private research, exploit details or unpublished source files into a public issue or pull request.

For a concern about this publication website, downloads or repository, open the repository's **Security** tab and choose **Report a vulnerability** when private reporting is available:

https://github.com/thereelninoninkovic/abv-labs-publications/security/advisories/new

Include the affected public URL or filename, the observed behavior and the smallest safe explanation needed to understand the risk. Redact sensitive information. Do not test against other people's accounts or data.

If private reporting is unavailable, do not publish the details. You may open a public issue asking only for a private reporting route, without describing the vulnerability or attaching files. This repository does not publish a separate security email address.

A security report does not guarantee a response time, a reward or acceptance of a proposed fix. Ordinary article corrections belong in the reader-error issue form; website layout or navigation problems belong in the site-bug form.
