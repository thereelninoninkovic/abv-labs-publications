What is in the data download?

Selected observations from 25 historical paired comparisons, five-size summaries, calculated comparisons and plain measurement definitions. The benchmark was not rerun to prepare the article.

Each size has five runs of each method. The two methods’ medians are calculated separately. The article explains how to read the numbers and which memory the measurement excludes.

Original implementation code and the private research archive are outside this reader download.
